# AI 圆桌 · 安装与使用指南

AI 圆桌是一个 Windows 电脑上的小程序：Claude、GPT、Gemini 三位顶级 AI 坐在一张“圆桌”边，一起帮你讨论问题，更重要的是一起帮你写稿、改稿。
由黑喵船长分享。首次安装请优先阅读 README.md。

## 一、准备工作（只需要做一次）

### 1. 确认电脑

- Windows 10 或 Windows 11，64 位。
- 自带的 Edge 浏览器（Windows 10/11 一般都有；没有的话装 Chrome 也可以）。
- 能连接你自己选择的 API 服务。

### 2. 安装 Python 3.13（必须是 3.13）

AI 圆桌需要 Python 3.13 才能运行。注意版本必须是 **3.13**，3.12、3.14 都不行。

1. 打开 Python 官网下载页：https://www.python.org/downloads/windows/
2. 在列表里找到 **Python 3.13.x**（x 是任意数字，选最新的那个），点 **Windows installer (64-bit)** 下载。
3. 双击下载好的安装程序。
4. 在第一个界面，**先勾选最下面的「Add python.exe to PATH」**，再点 **「Install Now」**。
5. 等它装完，看到「Setup was successful」就可以关掉了。

已经装过 Python 3.13 的电脑可以跳过这一步。

### 3. 网络

能否直连取决于你选择的 API 平台及网络环境，不统一要求代理。不修改系统代理；请按服务商的实际说明配置。

## 二、安装 AI 圆桌

### 1. 解压程序包

1. 把收到的「AI圆桌-v3.0-完整程序包.zip」放到一个固定的地方，比如「文档」文件夹。
2. 右键点它 →「全部解压缩」→「解压缩」。
3. 解压后会得到一个「AI-Roundtable」文件夹，以后程序就放在这里，**不要再移动或删除这个文件夹**。

注意：一定要先解压再用，不要在压缩包里直接双击文件。

### 2. 在桌面放一个图标

1. 打开「AI-Roundtable」文件夹。
2. 双击 **「创建桌面快捷方式.cmd」**。
3. 弹出一个黑色窗口，显示「已创建快捷方式」，按任意键关闭它。
4. 回到桌面，会看到一个深蓝底、青色小机器人图标的 **「AI 圆桌」**。以后双击它就能打开程序。

如系统拦截，请先核对下载来源和文件，再决定是否运行，不要关闭系统防护。
如果黑色窗口里提示「没有找到 Python 3.13」：说明上一步的 Python 没装好，请按「一、2」重新安装。
如果桌面图标显示成白纸或旧图标：在桌面空白处按一下 F5 刷新。

## 三、第一次打开：填写密钥

AI 圆桌本身不收费，调用 AI 用的是你自己在 AI 平台上的账户，所以需要先填一把「密钥」（API Key）。

1. 双击桌面的「AI 圆桌」，会打开一个独立窗口。
2. 点左侧栏下方的 **「设置」** 图标（几条横线的那个），选 **「连接」** 页。
3. 在你使用的平台那一栏填入密钥：
   - 程序内置了两条线路，两个平台用其中一个就行，都用上的话一条是主线路、另一条自动当备用：
     - CherryIn 官网：https://open.cherryin.ai/
     - AIHubMix 官网：https://aihubmix.com/
     在官网注册账户、充值后，到平台后台创建一把 API Key（密钥），复制下来，粘贴到 AI 圆桌里对应平台的那一栏。
   - 用别的平台也可以：在「连接」页下方的自定义线路里，填上平台给你的接口地址和密钥，点「＋ 添加这条自定义线路」。
   - 至少填一条就能用。填了多条时，可以上下拖动线路调整顺序，排在最上面的是主线路，主线路出问题时会自动换到下一条。
4. 点 **「检查已填写的线路」**，显示可用就完成了。

关于密钥的安全：

- 密钥只保存在你这台电脑上，而且是加密保存的，不会上传到任何地方。
- 加密跟这台电脑的 Windows 账户绑定，复制到别的电脑上也读不出来，所以换电脑要重新填。
- 不要把密钥发给别人，也不要截图发群里。

不想先花钱，只想看看界面：双击文件夹里的 **「演示模式.cmd」**，用模拟回复体验全部功能，不需要密钥，不花钱。

## 四、怎么用

窗口左侧竖栏有两个主要入口：**「聊聊」**（对话气泡图标）和 **「写作」**（笔的图标）。

### 1. 聊聊：三位 AI 一起讨论

- 在下方输入框写问题，按 Enter 发送（Shift+Enter 换行）。三位 AI 会先**各自独立**说出自己的想法，互相不点评。遇到点子、方向、方案这类问题，每位会各给至少 3 个不同的想法，并说明最推荐哪个（你在问题里写明“只要一个”就按你说的来）。
- 每轮回复结束后，输入框上方会出现几个「下一步」按钮，会根据情况变化：
  - 刚出完方案：**再各出 3 个新方案**（不满意就再来一批）、**互相点评一下**（简短点评，不再出新方案）、**完善细化推荐的方案**、**我选一个方案…**（填上你看中的那个，让大家点评）。
  - 点评或讨论之后：**继续讨论**、**汇总成一个方案**（由一位 AI 汇总）、**再各出 3 个新方案**、**我选一个方案…**。
- 「讨论 2 轮 / 3 轮」则是先各说各的，再自动互相回应。
- 输入 **@** 可以点名只让某一位回答；「发给」可以选「大家」或「只问某位」。
- 顶部点成员名字可以让 TA 暂时不发言；拖动名字可以调整发言顺序。
- 可以粘贴截图、拖入图片，让 AI 看图回答。
- 左边列表顶部的三个头像，可以和某一位 AI 单独聊天。
- 每个聊天有自己的小图标，点聊天顶部的图标可以换图案、颜色，或上传自己的照片。

### 2. 写作：三位 AI 帮你写、改、优化

1. 点左侧「写作」，再点右上角 **+** 新建稿件，选一个场景：公众号/自媒体文章、短视频口播脚本、工作文档、故事/小说/短剧。
2. 窗口分左右两半：**左边是工作区**（AI 写的东西都在这里），**右边是底稿**（你的正文，自动保存）。
3. 工作区有两个页签：

**基础起稿**：在输入框写这次要写什么，点 **「生成」**，选中的 AI 各写一版。
- 喜欢哪一版，点卡片上的 **「设为底稿」**，它就进到右边。
- 「重写」再来一轮，「续写」接着底稿往下写，「并排对比」把几版放在一起比。

**点评修改**：底稿写好后用来打磨。
- 「点评」：AI 只给意见。点评卡片上的「按点评修改」可以让 AI 按意见改出新版本。
- 「生成」：点评加修改，直接给出新版本。
- 想只改某一段：先在右边底稿里**选中那一段**，写下想要的感觉，点「重写本段」；改好的卡片上点「融入底稿」就替换进去。

4. 下方的小圆点决定 **谁来干**：亮的参与，灰的不参与。选几位，费用就约是一位的几倍。
- **转分镜提示词**（故事 / 小说 / 短剧场景）：选中一段剧情，点「转分镜提示词」，选好画风和画幅（默认只出中文，可勾选同时出英文）。AI 会给出人物资产、场景资产（先出角色和场景参考图）和每个镜头一段完整的视频提示词（风格、人物、场景、动作、运镜、台词、音效写在一起），一键复制就能拿去 LibTV、即梦等工具出片。
  - **模板**：窗口最上面可以选模板。「默认模板」是自带格式；也可以「新建模板」粘贴或上传自己的格式（最多 3 个），并「设为默认」，每次生成前选一个即可。
5. 输入框旁的 **「资料」** 可以加参考资料：Word、PDF、文本文档、图片、网页链接，或直接粘贴文字。AI 写的时候会参考它们。
6. 每张卡片上可以：复制、删除、**重新生成**（同一位 AI 再写一次）、标 ☆收藏 或 ♡爱心（标了的会一直留着，其他的可以一键「清理未标记」）。
7. 改错了不用怕：底稿里可以按 **Ctrl+Z** 撤销；右上角 **「历史版本」** 能找回以前的版本。
8. 写完后点右上角的下载图标，可以导出 **Word 文档** 或 **Markdown**，文件在电脑的「下载」文件夹里。

### 3. 看花了多少

- 窗口顶部会显示「本轮 / 本聊」大约用了多少积分。
- 左侧竖栏的「用量」图标可以看明细。

## 五、常见问题

**双击桌面图标没反应？**
等几秒，第一次打开会慢一点。还是没有反应的话，打开「AI-Roundtable」文件夹，双击「启动AI圆桌.cmd」，看看提示什么。最常见的原因是没装 Python 3.13。

**关掉窗口后程序还在运行吗？**
关掉窗口约 10 秒后程序会自动退出，不用管。重复双击图标也只会打开一个窗口。

**提示密钥无效、余额不足或连不上？**
先确认 VPN / 代理已经打开，并开启了「系统代理」或「全局 / TUN 模式」（最常见的原因就是忘了开代理）。然后去「设置 → 连接」点「检查已填写的线路」。其他常见原因：密钥复制少了字符、平台账户没余额。

**我把 AI-Roundtable 文件夹挪了位置，图标打不开了？**
在新位置重新双击一次「创建桌面快捷方式.cmd」即可。

**聊天记录和稿子存在哪里？**
都在「AI-Roundtable\data」文件夹里，只在你自己的电脑上。备份这个文件夹就等于备份了全部内容。

**以后收到新版本怎么升级？**
把新程序包解压，把里面的文件覆盖到原来的「AI-Roundtable」文件夹里，**注意保留 data 文件夹**。聊天记录、稿子、密钥都会保留。

**不想用了，怎么卸载？**
删除桌面的「AI 圆桌」图标，再删除整个「AI-Roundtable」文件夹即可（会连同聊天记录和稿子一起删除，需要的话先备份 data 文件夹）。Python 可以在 Windows「设置 → 应用」里卸载。

更详细的功能说明见同一文件夹里的「使用说明.txt」。
